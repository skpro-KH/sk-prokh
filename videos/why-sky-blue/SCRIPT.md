## ដាក់សំឡេងផ្ទាល់ខ្លួន

1. ថតសំឡេងតាមស្គ្រីបខាងលើ រក្សាទុកជា `.wav`
2. Render ម្ដងទៀត៖

```bash
cd videos/why-sky-blue
node src/render.js --voice /path/to/voice.wav
```

Script នឹង៖ កាត់ផ្នែកស្ងាត់ (>0.35s, ក្រោម −40 dB) · Normalize សំឡេង (−16 LUFS) · ពង្រីក/បង្រួមឈុតទាំងអស់ឱ្យស្មើប្រវែងសំឡេង · លាយជាមួយ whoosh និងភ្លេងផ្ទៃខាងក្រោយ។

កែអត្ថបទ/ពេលវេលា/កាត នៅក្នុង `src/scenes.json`។ ត្រូវការ: Node + Playwright (Chromium) + ffmpeg។
